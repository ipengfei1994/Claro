# Claro Portfolio Site

基于 React、TypeScript、Vite 与 Tailwind CSS 的独立工程案例网站。内容来自 Claro 仓库中的代码、项目记录、保留运行日志与真实界面截图。

## 本地运行

```powershell
cd portfolio-site
npm install
npm run dev
```

默认地址为 `http://localhost:5173`。

## 验证

```powershell
npm run lint
npm run build
npm run preview
```

## 内容边界

- 案例基线为 `main @ 6a78879`，整理日期为 2026-11-26。
- 所有业务数据均为合成样本，处置记录均为模拟，不代表线上部署。
- 测试与性能结果引用保留日志，不是本次重新执行主项目测试所得。
- `public/evidence/` 保存案例引用的主要文档；`public/assets/` 保存真实截图与图。
- 本目录独立于 Claro 主业务代码，不参与主项目启动。
